# ZhanFinance Telegram Bot Microservice

Микросервис Telegram-бота для платформы бухгалтерского аутсорсинга «ЖАН FINANCE» (JF-1C).

Обеспечивает взаимодействие с клиентами через Telegram (просмотр задач, документов, статусов) и надежную асинхронную доставку системных уведомлений из основного монолита JF-1C по паттерну Transactional Outbox.

Подробная архитектурная карта и схема взаимодействия описаны в файле [ARCHITECTURE.md](ARCHITECTURE.md).

---

## Требования

- **Java**: 17+
- **Gradle**: 8.x (или встроенный `./gradlew`)
- **Основной бэкенд JF-1C**: запущен на порту 8080 (или доступен по сети)
- **Токен Telegram-бота**: полученный у [@BotFather](https://t.me/botfather)

---

## Конфигурация (.env)

Перед первым запуском скопируйте `.env.example` в `.env`:

```bash
cp .env.example .env
```

Параметры конфигурации:

| Переменная | Назначение | Пример значения по умолчанию |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | Секретный токен бота от BotFather | `123456789:ABCdefGHI...` |
| `TELEGRAM_BOT_USERNAME` | Имя пользователя бота в Telegram (без `@`) | `zhan_finance_bot` |
| `JF_BACKEND_BASE_URL` | Базовый URL внутреннего API бэкенда JF-1C | `http://localhost:8080/api` |
| `INTERNAL_BOT_TOKEN` | Общий секретный токен для внутреннего API (`X-Internal-Token`) | `secret_internal_bot_token_change_in_production` |
| `SERVER_PORT` | Порт приложения (опционально) | `8081` |

Если `TELEGRAM_BOT_TOKEN` не указан или равен тестовой заглушке (`000000...`), сервис автоматически переходит в безопасный режим: фоновый шедулер продолжает работу, а Long Polling отключается во избежание сетевых ошибок соединения с Telegram.

## Запуск и сборка

### Локальный запуск через Gradle
При запуске таски `bootRun` переменные окружения автоматически загружаются из файла `.env`:

```bash
./gradlew bootRun
```

### Запуск тестов
```bash
./gradlew test
```

### Сборка JAR-архива
```bash
./gradlew bootJar
```
Собранный архив будет находиться в директории `build/libs/zhan-finance-tgbot-0.0.1-SNAPSHOT.jar`.

### Запуск в Docker
Сборка и запуск контейнера:

```bash
docker build -t zhan-finance-tgbot .
docker run --env-file .env zhan-finance-tgbot
```

## Команды бота

| Команда | Описание |
|---|---|
| `/start` | Приветствие и инструкция по привязке аккаунта |
| `/start <token>` | Привязка Telegram-аккаунта по 15-минутному токену из веб-кабинета |
| `/tasks` | Список текущих задач клиента со статусами и ссылками |
| `/docs` | Список недавних документов клиента |
| `/status` | Информация о текущей привязке (компания, ФИО) |
| `/unlink` | Отвязка Telegram-аккаунта от системы |
| `/help` | Справка по всем доступным командам |

## Взаимодействие с основным бэкендом JF-1C

Микросервис обращается к бэкенду по внутренним эндпоинтам `/api/v1/internal/**`, передавая заголовок:
`X-Internal-Token: ${INTERNAL_BOT_TOKEN}`

Монолит бэкенда валидирует этот заголовок и предоставляет доступ к операциям управления уведомлениями и данными клиентов (`ROLE_INTERNAL_BOT`).
